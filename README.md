# Coders — Learn. Build. Level Up.

A GitHub-first student coding academy built with Next.js, TypeScript, Tailwind CSS, and Supabase.

## Core
- GitHub-only authentication
- Public course browsing
- Beginner → advanced learning paths
- XP, levels, streaks and achievements
- Personal progress and saved code
- Responsive coding-learning UI
- Supabase Row Level Security
- GitHub Actions deployment

## Planned languages
HTML, CSS, JavaScript, TypeScript, Python, Java, C, C++, C#, Go, Rust, PHP, Ruby, Kotlin, Swift, SQL, Bash, Git/GitHub, React, Next.js, Node.js, DSA, databases, APIs, AI/ML fundamentals, cybersecurity and DevOps.

## Development
Create `.env.local` with:
```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

Never expose a Supabase secret/service-role key in the browser.
